# PROJECT ABSTRACT — canonical / 要旨(正典)

*Single source. Edit here first; README, Hackaday.io, and docs radiate from this text.*

**EN.** PTSG-WPMS-Formation is the first *subtraction profile* of the PTSG ecosystem: the L2 Formation of Wave-Packet Modulation Synthesis inside FPGA Spectrum Engine, produced from the master data ISA (PTSG-CPU-Formation) by subtraction and minimal addition on the frozen PTSG-Core. It keeps a decision register in which every choice is keyed to a master ID — inherit, restrict, omit, extend — and adds only what the master left to its first customer: a register map of eight 16-word packet blocks with an inbox for external writers; a sweep sequencer that presents each packet's parameters to the pipeline as one bundle at packet start and drives the Core's Stay length, so that one Stay is one packet and the Stay counter is the difference engine's *k*; and two instructions — a step-toward for level glides and a masked block copy for atomic updates. Every write falls between two latches of the block it touches, so zipper noise is impossible by construction. Numbers bind to DE10-nano and are measured, not promised.

**JA.** PTSG-WPMS-Formation は PTSG エコシステム最初の*引き算プロファイル*——FPGA Spectrum Engine 内の波束変調合成の L2 Formation——であり、凍結された PTSG-Core の上でマスターデータ ISA(PTSG-CPU-Formation)から引き算と最小限の足し算で作られる。全決定をマスター ID に紐づける決定台帳(INHERIT / RESTRICT / OMIT / EXTEND)を持ち、マスターが最初の顧客に残したものだけを加える: 16 語のパケットブロック八つと外部書き手のための inbox からなるレジスタマップ;各パケットのパラメータをパケット開始時に一束(バンドル)としてパイプラインへ提示し、Core の Stay 長を駆動する掃引シーケンサ(一 Stay = 一パケット、ステイカウンタ = 差分エンジンの *k*);そしてレベル滑走のためのステップ・トワードと、原子的更新のためのマスク付きブロックコピーの二命令。あらゆる書込みは、そのブロックの二つのラッチの間に収まるので、ジッパーノイズは構造的に不可能。数値は DE10-nano に束縛され、約束ではなく計測される。
